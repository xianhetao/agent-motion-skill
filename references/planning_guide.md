# 理解文案 · 分镜规划指南

**这一步决定了「理解文案」和「机械铺字幕」的分水岭。** 用户明确否决过只铺字幕的版本——包装必须先读片、读懂论证结构，再决定每张卡片卡在哪句话、什么时候出。

## 为什么先做这步

口播片不是字幕条的集合。它有一套论证结构（钩子 → 问题 → 核心论点 → 证据 → 升华 → 警告），观众靠视觉锚点（金句、数据、章节）记住重点。导演式包装的价值，就是把这些锚点**卡在说到的那一刻**浮现，强化而非干扰口播。

## 四步法

### 1. 看片 + 读字幕
- 抽几帧确认：画面构图（人脸位置）、是否已有烧录字幕、画幅（竖/横）、有没有笔误。
- 通读 SRT，按时间线理解全片论证结构，不要只看单句。

### 2. 找结构，标强化段
按「一个功能一块」标出 5 类锚点：

| 类型 | 作用 | 落点元素 | 出现时机 |
|---|---|---|---|
| **钩子** | 开场抓住注意力 | 章节卡 / 金句花字 | 片头 0–5s |
| **核心论点** | 全片最想让人记住的一句 | 金句花字（长 hold） | 论点说出时 |
| **数据块** | 用数字建立可信度 | 数字 count-up 卡 | 说到数字时 |
| **章节** | 结构转折/分段 | 章节卡 | 转折点 |
| **警告/升华** | 收尾的情绪落点 | 金句花字 | 收尾 |

### 3. 给每张卡片定锚点词（cue）
每张卡片配一个**锚点词**（cue）——主讲人说到它时卡片浮现。选片中最具代表性的实词（如「把关」「子号」「播放量」）。cue 命中词表时以**真实说话时刻**为准；若 ASR 写法不一致搜不到，才落到手配的 `at` 兜底时刻。

> 锚点词优先选「片中只出现一次」的实词，避免卡到错误位置。

### 4. 写分镜细案 + 产 config.json
把上面的判断落成文字（分镜细案），再转成 `references/workflow_director.md` 里的 config.json：

```jsonc
{
  "name": "主讲", "role": "企业内容营销 · 筛选与把关", "corner": "企业内容观察",
  "stats": [
    {"value": 1.2, "suffix": "亿", "label": "全网播放", "cue": "播放量", "at": 89.9},
    {"value": 22.8, "suffix": "万", "label": "30天涨粉", "cue": "涨粉", "at": 93.7}
  ],
  "keywords": [
    {"text": "不是创意，是筛选和把关", "cue": "把关", "at": 41.9, "hold": 5.0},
    {"text": "主号保调性，子号做试验", "cue": "子号", "at": 131.3, "hold": 4.0}
  ],
  "chapter": "真正缺的能力", "chapterNo": "PART 03", "chapterAt": 38.0, "chapterHold": 2.4
}
```

## 分镜细案示例（洁丽雅口播案例）

```
四幕结构：破（门槛归零） → 立（核心论点） → 核（数据证据） → 证/升（品牌资产/主号子号/警告）
强化段：
  T1 钩子 0–3s：传播门槛归零，企业拼什么？
  T2 核心论点 39–46s：「不是创意，是筛选和把关」（金句，hold 5s）
  数据块 89.9/93.7/96.4s：1.2亿播放 / 22.8万涨粉 / 500万+带货（count-up）
  B2 品牌资产 120–126s：流量来得快，压进去的是品牌资产
  B3 主号子号 131–135s：「主号保调性，子号做试验」（金句）
  B4 警告 139–142s：「千万别拿主号去赌」（金句，短 hold）
章节卡 38s：PART 03 真正缺的能力
角标全程：企业内容观察
```

## 常见错误
- 每段塞太多字 → 拆段或缩短，金句花字一行 ≤ 14 字最佳。
- cue 词选片中多次出现的词 → 卡错位置；选唯一实词。
- 全片只用一种元素（只有字幕） → 用章节/数字/花字交替制造节奏。
- 忘记先看片确认画幅/字幕 → 竖屏源直接渲横屏会把脸切掉（见 workflow_director.md）。
- 锚点时刻全靠估 → 以 SRT 时间码 / cue 真实说话时刻为准，不要臆测。
