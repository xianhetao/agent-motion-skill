# 口播包装：视觉与动效规范（用户拍板，通用）

> 从 test-01 项目 v4→v18 的 14 轮验收中提炼。这些不是审美偏好，是**反复被指出、反复修正**
> 后确定的硬规则。做口播包装时默认遵守，除非用户另有要求。
> 项目内的完整真值：`work/test-01/SPEC.md`。

## 1. 生命周期（最高优先级）

- 元素生命周期 = **口播覆盖周期**：按文案出场，按「接下来的内容」出画。
- 常驻**仅限**结构性上下文（三点列表、新旧对比这类跨句结构）。
- 声画刺激来自「出现 + 消失」，不要让元素挂在画面上等下一句。
- **编组与次序**：一组元素要么编组同动（卡片 + 其托板一起升起），要么按次序逐个出
  （从上到下 / 从左到右）。**宿主没出时，附属元素（隔板/衬底）不得提前出现**。
- **图片要逐个指代口播名词**：口播说「一家报社、一个电视台」就出两张独立的图、
  一张一张按序入场，不能用一张合成图糊过去。

## 2. 排版（竖屏）

- **入画落视觉中心**：口播头像占一角、画面空旷时，新元素（图/文）尽可能落在
  垂直 1/2 附近的视觉中心；后续内容可上移一点，其它内容接着往下排。
- **两组元素之间的空白面积不得大于有内容的区域**（组间距 ≤ 组内行距）。
  典型错误：标题/名牌组在上、数据组在下，中间空一大片。
- **格式塔相近相邻**：列举型元素间距必须小于元素自身高度，间距大了组感就散。
- 大面积空白按**一列**排：强调卡在顶部（更高更大），子项等宽等距均分下方。
- 去重：小标题与下方大卡/子项文案重复时，删小标题。

## 2.1 人在讲构图（原片 = 图文排版里的「图片」）

> **铁律（2026-10-24 用户拍板）**：P1 阶段定稿的关键帧（KF1–KF6）是**唯一视觉基准**。
> 某段已有 KF 覆盖 → 直接用那张 KF 的画面做动效，**严禁另造版式**（曾犯：给已有 KF2 的
> 「筛过一遍」段另做了一套「编号列表 + 纸面分栏」，被否）。
> 只有**没有 KF 覆盖的抽象段落**才做「人在讲」，且人在讲也必须沿用 KF 语言：
> 纸底 `#efe9dd` / 墨 `#2b2722` / 深红 `#9e2b25` / 白卡 `#fffdf8` / 整块色条，
> **人窗就是版面里的一张卡**（圆角 28，与其它卡同宽同高同一套对齐），不是另起一套分栏。

- **原片在视频里等价于图文排版中的图片**：它的占比、落位按排版规范决定，**不是死全屏**。参考花叔 talking-head 模板「人小窗 + 信息卡」——人占一区、文字占一区，互为图文。
- **九宫格定位决定关键字落位**：把输出画面（1080×1920）按九宫格想，先判断主播在原片里处在哪一格，再定关键字位置（**不要默认钉在顶部**）：
  - 人在**中**（最常见 16:9 居中构图）→ 关键字放**下方**（放上方压脸、不好看）；
  - 人在**下** → 关键字放**上方**；人在**上** → 关键字放**下方**；
  - 人在**左** → 关键字放**右侧**；人在**右** → 关键字放**左侧**。
- **原片可不全屏**：构图需要时把原片缩放放进九宫格某一格（如左下 / 右中），其余区域用背景色 / 虚化补位，关键字落在邻格——这就是「图片占位」，不是人必须占满屏。
- **硬约束**：关键字不得压人脸主体；若人脸跨格，以「不压脸」优先于上述默认落位。
- 关键字块形态沿用 §3 动效（20px expoOut 上浮 + 0.10s 硬间隙），仅**位置**随九宫格灵活。
- **渲染前先确认构图**：用 PIL 出一张静态预览图（原片落位 + 关键字位置标好），给用户确认「视频放哪格、字放哪」没问题，再渲染视频。这是 `pipeline.md` P5 渲染前对齐在 L1 上的具体落地，**不可跳过**。

### 2.1.1 素材是「大特写占满全帧」时（最常见的坑）
- 这种素材**没有空白可放字**，只能做**画中画**：原片缩成竖版圆角窗放进一栏，其余用纸面补位，文字占另一栏。不要试图在原帧上压字（会压脸）。
- **窗口宽高比必须小于源宽高比**（`ratio = w/h < src_w/src_h`），否则 cover 裁切会在**纵向**切掉大半张脸。竖屏 9:16 源用 `ratio≈0.34`，只裁两侧约 40%、纵向不裁，脸完整。方形窗（1:1）在 9:16 特写上必然裁掉脑门和下巴——**禁用**。
- 窗内不出现黑边/残缺字幕条；若原片底部有烧录字幕，允许保留（属原片语境），但不得被窗沿切半。

### 2.1.2 另一栏的文字：论点列表（填满 + 自带动画）
- 单行关键字在一整栏里会显得又空又小。**改成整段的「编号 + 论点」列表**（2–4 条），既把栏撑满，又是结构性上下文（§3 允许常驻）。
- 当前正在讲的条目：**墨色实显 + 深红序号**；未到的条目压灰（纸面上 ≈4.6:1，仍可读，不许淡到看不见）；已讲过的略深一档。
- 条目切换随口播推进，切换时该条做 20px expoOut 上浮；列表属常驻结构，**不需要 0.10s 硬间隙**。
- **列表与人物窗等高对齐**（同起同收），否则一侧撑满、另一侧堆中间 → 画面失衡。
- **组间距上限 1.7 倍行高**：宁可整块居中留边，也不许把条目拉散（相邻成组原则优先于「填满」）。
- 中文断行**人工指定**（`\n`），不靠算法硬切，避免从词中间断开。

## 3. 动效（对齐 huashu-motion 动画系统 + test-01 拍板）

> 参数来源：花叔 huashu-motion 的「动画系统」（Easing 库 4 条 + Duration 字典 + Stagger 法则
> + Human-Centric Pausing）与 test-01 v4→v18 反复验收拍板的硬规则。两处冲突时以本表为准。
> 渲染时必须逐条遵守，参数直接来自下表，不在脚本里另写一套。

### 3.0 运动曲线库（只用这 4 条，禁用其它）
| 名称 | 公式 | 用途 |
|---|---|---|
| **expoOut**（默认） | `1 - 2^(-10t)` | 90% 的入场：快速起步、长尾落定，premium 重量感 |
| **overshoot** | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 强调弹出 / 关键词卡 / 按钮浮现（轻微过冲落定） |
| **expoIn** | `2^(10(t-1))` | 出场（10% 用这个，快撤） |
| **linear** | `t` | 底色 fade / 纸纹移动 |

### 3.1 时长字典（按元素体量分级）
| 事件 | 时长 | 曲线 | 备注 |
|---|---|---|---|
| 小元素入场（pill/标签/引导行） | 300ms | expoOut | 快 |
| 中元素入场（卡片/数字/论证句） | 500ms | expoOut | 默认档 |
| hero 入场（大标题/主卡） | 700–900ms | expoOut | 段落核心句 |
| 出场 | 200–300ms | expoIn / 快撤 | **永远快于入场** |
| 强调落定（scale 1.6→1） | 220ms | — | 接 shake，必配音效 |
| 图片脉冲 | ≤400ms | — | 峰值 ≤105%，精确回原值 |

### 3.2 入场
- 位移 **20px 上浮/滑入** + expoOut（长尾，不是生硬 linear）。
- 列表 / 多元素按口播节奏 stagger，**相邻 delay 30–80ms**（不为 0、不超 100ms）。
- 关键词卡 / 标签弹出可用 **overshoot** 做轻微过冲落定，更跳。

### 3.3 出场
- 200–300ms 快撤，**快于入场**；曲线 expoIn 或硬撤。
- **淡出先于运动清零**：带位移 / 缩放的出场，不透明度在运动时长约 **70%** 处降到 0
  （尾段在不可见中完成），否则有视觉残留；纯淡出不受限。

### 3.4 交接
- **同镜元素更替**：上一元素撤净 → **0.10s 硬间隙**（两者都不可见）→ 下一元素入场；
  位置相近的元素**严禁交叠淡入淡出**。
- **整段风格切换**（A/B 模式切换、KF 关键帧之间）：背景同色直接**硬切**；
  背景 / 内容明显变化才用转场（见 §6）。

### 3.5 停留
- 元素生命周期 = **口播覆盖周期**：按文案出场、按「接下来的内容」出画（§1）。
- 纯视觉强调（不承载口播的词 / 数字）：最短停留 **400–600ms** 保证可读。
- **Human-Centric Pausing**：任何关键结果 / 强调落定后，强制停 **≥300ms** 再撤，
  给眼睛重置聚焦（花叔体系强制项，非建议）。

### 3.6 强调
- 落定：scale 1.6→1（220ms）+ shake（amp 6–14, decay 7–8），shake 锚点与落定同步；
  由大到小的入场**必须配音效**。
- 图片强调：快速脉冲，峰值 ≤105%、总时长 ≤400ms、精确回原尺寸原位置。
- 缩放回落**必须回 100%**，不能落到 80/90%。

### 3.7 禁止项
- ❌ 结尾 fade-to-black：成片 / 段必须结束在清晰锐利帧（花叔强制）。
- ❌ 图片停留期正弦抖动 / 呼吸缩放：入画后完全静止；抖动只用于线条 / 文字强调。
- ❌ 缩放回落不回 100%。
- ❌ 同镜元素交叠淡入淡出（用 3.4 硬间隙）。
- ❌ 用 expoOut / overshoot / expoIn / linear 之外的曲线（如 smoothstep、ease-in-out 当默认）。

## 4. 图片

- 统一规范：圆角 20 + 暖调叠加 `rgba(70,60,50,.08)` + 墨色细边 3px `rgba(38,40,46,.14)`。
- **方向校验**：AI 生成图入库前**必须目检方向**（曾有整张 180° 颠倒：人群头朝下、
  台灯从下往上照）。源图倒了就 `sips -r 180` 转图，不在代码里翻。
- **去水印**：ImageGen 出图带角标水印，用 `ffmpeg -vf crop=W:H:0:0` 裁掉底部。
- **图 + 文组合不加装饰线条**：竖线/横线分隔、贯穿线一律不要，简洁优先。
- 无真实品牌/台标/机构名（商标权风险）；可用文字标牌 + 实拍替代 logo。

## 5. 文字层级

**字体规范（对齐 huashu-motion talking-head 模板）**：中文只用 **Noto Sans SC 两档字重——
正文/引导行 500、强调一律 900**（标题卡/关键词卡/花字/名牌/大数字汉字全 900）；
数字用无衬线窄体（Inter 700/800 或 Barlow Condensed 700）。
**不要用中间档 600/700 当强调**——屏摄压缩后横画发虚；也不要用横细竖粗的展示字体
（如得意黑 Smiley Sans，斜体且横画太细，已被用户否决）。选字体先出对比样张给用户目测。

| 层级 | 样式 |
|---|---|
| H1 段落大标题 | 148–190px / 900，PLATE 卡 + 朱红 rule |
| H2 大字卡 | 78px/900，PLATE 卡 + rule |
| H3 引导行 | 30px/500，.62 墨 |
| 关键词卡 | **48px/900/#3f4652 + NAMEPLATE 卡，全片同一样式** |
| 子项行 | 标签 40px/500/.6 墨；数值 84px/700；单位 44px 朱红 |
| 正文信息 | 28–40px，.4–.62 墨 |

- 标题**无标点**（问号视情况）；间隔号用空格或竖线分行；长句空格断句。
- 卡片内文字与容器必须留间隔（带左竖条的卡片 pad ≥ 30）。

## 6. 转场与风格

- **硬切原则**：背景同色、内容相近 → 直接硬切，不做任何转场特效。
  转场只在画面内容或背景有明显对比变化时才用。
- 纸面风格**禁**：cast shadow 投影、黑色 vignette、照片压暗、照片羽化。

## 7. 口播小窗（画中画）

- **形状**：圆形或方形小窗，置于输出画面某位置（角落或边缘），不挤主内容。
- **何时用**：原片背景复杂、抠不干净时，用画中画替代抠像（见 `pipeline.md` §5.1 背景可抠性判定）。
- **边距**：小窗四周必须留边距（实测屏幕 ≥44px），不挤其它元素；
  设计坐标 ≠ 屏幕坐标（透视放大约 1.059，`CAMZ≈1612`），要按实测反推。
- **不遮挡**：人窗不得压主视觉（动效主体 / 大标题 / 数据卡）；
  关键字也不得压人脸（人在讲段放头顶上方）。
