# 口播包装：视觉与动效规范（用户拍板，通用）

> 从 test-01 项目 v4→v18 的 14 轮验收中提炼。这些不是审美偏好，是**反复被指出、反复修正**
> 后确定的硬规则。做口播包装时默认遵守，除非用户另有要求。
> 项目内的完整真值：`work/test-01/SPEC.md`。

## 1. 生命周期（最高优先级）

- 元素生命周期 = **口播覆盖周期**：按文案出场，按「接下来的内容」出画。
- 常驻**仅限**结构性上下文（三点列表、新旧对比这类跨句结构）。
- 声画刺激来自「出现 + 消失」，不要让元素挂在画面上等下一句。
- **编组与次序**：一组元素要么编组同动（卡片 + 其托板一起升起），要么按次序逐个出
  （从上到下 / 从左到右）。**宿主没出时，附属元素（隔板/衬底）不得提前出现**。
- **图片要逐个指代口播名词**：口播说「一家报社、一个电视台」就出两张独立的图、
  一张一张按序入场，不能用一张合成图糊过去。

## 2. 排版（竖屏）

- **入画落视觉中心**：口播头像占一角、画面空旷时，新元素（图/文）尽可能落在
  垂直 1/2 附近的视觉中心；后续内容可上移一点，其它内容接着往下排。
- **两组元素之间的空白面积不得大于有内容的区域**（组间距 ≤ 组内行距）。
  典型错误：标题/名牌组在上、数据组在下，中间空一大片。
- **格式塔相近相邻**：列举型元素间距必须小于元素自身高度，间距大了组感就散。
- 大面积空白按**一列**排：强调卡在顶部（更高更大），子项等宽等距均分下方。
- 去重：小标题与下方大卡/子项文案重复时，删小标题。

## 3. 动效

| 项 | 参数 |
|---|---|
| 入场 | 0.25–0.30s（快），ease-out，位移 20px 上浮/滑入；列表项按口播节奏 stagger |
| 出场 | 0.30s 快撤 |
| 交接 | 上一元素撤净 → **0.10s 硬间隙**（两者都不可见）→ 下一元素入场；位置相近的元素严禁交叠淡入淡出 |
| 强调落定 | scale 1.6→1（0.22s）+ shake（amp 6–14, decay 7–8），shake 锚点与落定同步；由大到小的入场**必须配音效** |
| 图片强调 | 快速脉冲：峰值 ≤105%，总时长 ≤0.4s，**精确回到原尺寸原位置** |

- **淡出先于运动清零**：带位移/缩放的出场，不透明度必须在运动时长约 **70%** 处降到 0
  （运动尾段在不可见中完成），否则会有视觉残留。纯淡出出场不受此限。
- **图片停留期完全静止**：入画后不得有正弦抖动、呼吸缩放等持续微动；
  抖动/颤动只用于线条或文字强调。**缩放回落必须回到 100%，不能落到 80/90%**。
- **信息必须自明**：画面上的数字/指标若语义不能被观众直接理解（如「82.4」是什么分），
  宁可不用，换成状态词（算法分发 → 一夜暴涨 → 一夜反噬）。

## 4. 图片

- 统一规范：圆角 20 + 暖调叠加 `rgba(70,60,50,.08)` + 墨色细边 3px `rgba(38,40,46,.14)`。
- **方向校验**：AI 生成图入库前**必须目检方向**（曾有整张 180° 颠倒：人群头朝下、
  台灯从下往上照）。源图倒了就 `sips -r 180` 转图，不在代码里翻。
- **去水印**：ImageGen 出图带角标水印，用 `ffmpeg -vf crop=W:H:0:0` 裁掉底部。
- **图 + 文组合不加装饰线条**：竖线/横线分隔、贯穿线一律不要，简洁优先。
- 无真实品牌/台标/机构名（商标权风险）；可用文字标牌 + 实拍替代 logo。

## 5. 文字层级

**字体规范（对齐 huashu-motion talking-head 模板）**：中文只用 **Noto Sans SC 两档字重——
正文/引导行 500、强调一律 900**（标题卡/关键词卡/花字/名牌/大数字汉字全 900）；
数字用无衬线窄体（Inter 700/800 或 Barlow Condensed 700）。
**不要用中间档 600/700 当强调**——屏摄压缩后横画发虚；也不要用横细竖粗的展示字体
（如得意黑 Smiley Sans，斜体且横画太细，已被用户否决）。选字体先出对比样张给用户目测。

| 层级 | 样式 |
|---|---|
| H1 段落大标题 | 148–190px / 900，PLATE 卡 + 朱红 rule |
| H2 大字卡 | 78px/900，PLATE 卡 + rule |
| H3 引导行 | 30px/500，.62 墨 |
| 关键词卡 | **48px/900/#3f4652 + NAMEPLATE 卡，全片同一样式** |
| 子项行 | 标签 40px/500/.6 墨；数值 84px/700；单位 44px 朱红 |
| 正文信息 | 28–40px，.4–.62 墨 |

- 标题**无标点**（问号视情况）；间隔号用空格或竖线分行；长句空格断句。
- 卡片内文字与容器必须留间隔（带左竖条的卡片 pad ≥ 30）。

## 6. 转场与风格

- **硬切原则**：背景同色、内容相近 → 直接硬切，不做任何转场特效。
  转场只在画面内容或背景有明显对比变化时才用。
- 纸面风格**禁**：cast shadow 投影、黑色 vignette、照片压暗、照片羽化。

## 7. 口播小窗

- 小窗四周必须留边距（实测屏幕 ≥44px），不挤其它元素；
  设计坐标 ≠ 屏幕坐标（透视放大约 1.059，`CAMZ≈1612`），要按实测反推。
